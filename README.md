# DroidRemote3

A one-word command that works on both Linux and Termux. It provides:
- QR code pairing
- 6-digit code fallback
- File transfer
- Media sending
- Notifications
- And more!

## How to Use

1. Run:

curl -s https://raw.githubusercontent.com/yourusername/DroidRemote3/main/install.sh | bash


2. Access the web interface:

http://localhost:5000
