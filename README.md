# DroidRemote3

A one-word command that works on both Linux and Termux. It provides:
- QR code pairing
- 6-digit code fallback
- File transfer
- Media sending
- Notifications
- And more!

## How to Use

1. Run:

git clone https://github.com/313WeeG/DroidRemote3.git

python3 -m venv venv                                 
source venv/bin/activate

cd DroidRemote3     
chmod +x install.sh     
./install.sh

python DroidRemote3.py


2. Access the web interface:

http://localhost:5000
